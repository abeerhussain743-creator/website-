# Aether — The Future Operating System for Modern Businesses

Premium AI company website built with Next.js, Three.js, Framer Motion, GSAP-ready patterns, and Lenis smooth scrolling.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber / Drei
- Lenis
- Lucide Icons

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```
