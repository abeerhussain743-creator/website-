# Axion — Premium AI Automation Website

Marketing site for Axion: AI automation systems, agents, workflows, and intelligent software.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Three.js / React Three Fiber / Drei
- Lucide Icons

## Develop

From the monorepo root:

```bash
npm run dev:axion
```

Or from this package:

```bash
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Build

```bash
npm run build:axion
```

## Design system

- Deep charcoal base (`#07090d`)
- Icy blue accent (`#6eb8e0`)
- Space Grotesk (display) + Manrope (body) + JetBrains Mono
- Signature 3D automation core with scroll-driven storytelling
